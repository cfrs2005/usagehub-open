# Contributing

Thanks for contributing to UsageHub Open.

1. Keep public client code independent of private infrastructure and local machine paths.
2. Do not add account data, telemetry captures, secrets, signing material, or production configuration.
3. Add or update tests when behavior changes.
4. Run `npm run check` and the relevant Android Gradle tasks before opening a pull request.
5. Keep ingest payloads allowlisted. New fields require an update to the public schema and a privacy review.

Issues and pull requests must use clear reproduction steps. Do not disclose tokens or personal data.
